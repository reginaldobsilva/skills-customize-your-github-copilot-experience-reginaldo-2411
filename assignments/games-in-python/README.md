# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras usando strings, loops e entrada de dados do usuário em Python.

## 📝 Tarefas

### 🛠️ Criar o Jogo da Forca

#### Descrição

Crie um jogo da Forca no qual o jogador adivinhe letras para revelar uma palavra oculta antes de esgotar as tentativas.

#### Requisitos

O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida.
- Solicitar palpites de letras ao jogador.
- Mostrar o progresso atual da palavra no formato `_ _ _`.
- Rastrear as tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir uma mensagem clara de vitória ou derrota.
